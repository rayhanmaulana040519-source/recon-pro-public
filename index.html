 VPS ACCESS / 06
Terminal VPS.
Jalankan tool dan perintah pada host dashboard, lalu pantau outputnya di sini.
 AKSES TERKONTROL

          
 PERINTAH VPS
Shell command runner
Jalankan perintah di seluruh VPS sesuai hak akun dashboard. Contoh: ls -la / atau bash /root/recon/recon.sh --update. Gunakan hanya pada sistem dan aset yang Anda berwenang kelola.

          
!
Shell memberi hak yang sama dengan akun Linux dashboard (bisa root) dan melewati pemeriksaan scope UI. Aktifkan hanya saat diperlukan, jangan buka port dashboard ke internet, dan akses melalui SSH tunnel. Prompt interaktif seperti editor/apt dialog tidak didukung.

          
OUTPUT VPSMemeriksa terminal…
Awal di / (akar seluruh filesystem). Ganti ke /root, /tmp, /etc, atau folder lain; pilihan tersimpan selama sesi browser.
Output perintah akan tampil di sini.
Perintah dimulai di direktori di atas. Ubah field direktori untuk perintah berikutnya; `cd` di dalam command hanya berlaku sekali.

          
Aktivasi: mulai dashboard dengan RECON_WEB_ENABLE_SHELL=1 bash recon.sh --web. Shell hanya aktif pada bind loopback dan saat ini tidak menyediakan terminal TTY/prompt stdin.
